# Персональная панель управления

Адаптивное веб-приложение с тёмной темой на русском языке: всё для учёбы и планирования в одном месте. Работает без сервера и без сборки, на чистых HTML, CSS и JavaScript.

## Возможности

- **Задачи**: добавление, удаление, отметка выполненных, фильтры, очистка выполненных
- **Калькулятор**: четыре действия, проценты, смена знака, история, ввод с клавиатуры
- **Расписание на неделю**: занятия по дням недели со временем
- **Английские слова**: карточки с переворотом, отметка «знаю», свой словарь
- **Результаты SAT**: математика и чтение/письмо, график, лучший и средний балл, целевой балл
- **Статистика**: сводка прогресса по задачам, словам и SAT на главной странице
- **Сохранение данных** в `localStorage` браузера, данные остаются после перезагрузки
- **Адаптивный дизайн**: боковое меню на компьютере, нижняя панель на телефоне

## Запуск локально

Сборка не нужна. Откройте `index.html` в браузере двойным щелчком.

Или запустите локальный сервер:

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите файлы проекта (команды ниже).
3. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту сайт будет доступен по адресу `https://ваш-логин.github.io/название-репозитория/`.

```bash
git init
git add .
git commit -m "Первая версия панели управления"
git branch -M main
git remote add origin https://github.com/ваш-логин/название-репозитория.git
git push -u origin main
```

## Хранение данных

Данные сохраняются в `localStorage` под ключом `dash_v1` и хранятся только в браузере пользователя. Между устройствами они не синхронизируются. Кнопка «Сбросить данные» в меню удаляет всё.

## Технологии

HTML5, CSS3 (grid, flexbox, CSS-переменные), JavaScript (ES5), шрифт Manrope из Google Fonts. Внешних библиотек нет.
